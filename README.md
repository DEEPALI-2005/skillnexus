# SkillNexus

A hyperlocal freelance ecosystem connecting clients with verified
local professionals.

## Stack
- Frontend: React, Vite, Tailwind, React Query, Socket.IO client
- Backend: Node, Express, MongoDB Atlas, Mongoose, Socket.IO
- Auth: JWT + Google OAuth + 2FA
- Payments: Razorpay
- Files: Cloudinary
- Email: Nodemailer

## Project Structure
- `skillnexus-backend/` - API server
- `skillnexus-frontend/` - React app
- `DESIGN.md` - design system (do not skip)
